# 02. じゃんけんゲーム

対応セクション: `10.javascript.md` の「関数の定義」「配列操作」「オブジェクト操作」「演算子」「DOM API」

演習08（配列操作）・09（オブジェクト操作）・07（スプレッド構文）の復習を兼ねた、じゃんけんゲームです。


課題
--------------------------------------------------------------------------------

`logic.js` の3つの関数を実装してください（`main.js`・`index.html`は実装済みです）。

1. `pickComputerHand()`
   `HANDS`（`"rock"` / `"scissors"` / `"paper"`）の中からランダムに1つ選んで返してください。

2. `judgeJanken(playerHand, computerHand)`
   `playerHand`から見た勝敗を判定してください。
   - グーはチョキに勝ち、チョキはパーに勝ち、パーはグーに勝ちます
   - 同じ手の場合は`"draw"`
   - 勝った場合は`"win"`、負けた場合は`"lose"`を返してください

3. `updateScore(score, result)`
   `score`（`{win, lose, draw}`）を`result`に応じて更新した、**新しいオブジェクト**を返してください。
   スプレッド構文を使い、**元の`score`オブジェクトを変更しないこと**（不変更新）に注意してください。


確認方法
--------------------------------------------------------------------------------

1. ロジック部分をターミナルで確認します。

   ```bash
   node challenges/02-rock-paper-scissors/check.js
   ```

2. 実際にゲームとして動作するか、ブラウザで確認します。
   リポジトリのルートで以下を実行します。

   ```bash
   npx serve .
   ```

   ブラウザで`http://localhost:3000/challenges/02-rock-paper-scissors/`を開き、
   グー・チョキ・パーのボタンを押して対戦できれば成功です。

どうしても分からない場合は、`answer/`フォルダの模範解答を確認してください。
