# 01. Hit and Blow

対応セクション: `10.javascript.md` の「配列操作」「等価演算子」「演算子」「関数の定義」「DOM API」

コンピューターが決めた**重複のない数字の並び**を、Hit（位置も数字も一致）・Blow（数字は合っているが位置が違う）
のヒントを頼りに当てるゲームです。


課題
--------------------------------------------------------------------------------

`logic.js` の3つの関数を実装してください（`main.js`・`index.html`は実装済みです）。

1. `generateSecretDigits(length)`
   `0`〜`9`の中から**重複なく**`length`個の数字を選び、配列で返してください。

2. `parseGuess(input, length)`
   ユーザーが入力した文字列を検証し、数字の配列に変換してください。
   以下のいずれかに該当する場合は`null`を返してください。
   - `length`桁ちょうどでない
   - 数字以外の文字が含まれている
   - 同じ数字が重複している

3. `judgeHitAndBlow(secret, guess)`
   `secret`（正解）と`guess`（予想）を比較し、`{ hit, blow }`の形で返してください。
   - `hit`: 位置・数字ともに一致している数
   - `blow`: 数字は`secret`に含まれているが、位置が違う数
   （`secret`・`guess`はどちらも重複のない数字の配列です）


確認方法
--------------------------------------------------------------------------------

1. ロジック部分をターミナルで確認します。

   ```bash
   node challenges/01-hit-and-blow/check.js
   ```

2. 実際にゲームとして動作するか、ブラウザで確認します。
   リポジトリのルートで以下を実行します。

   ```bash
   npx serve .
   ```

   ブラウザで`http://localhost:3000/challenges/01-hit-and-blow/`を開き、
   4桁の数字を入力してHit/Blowのヒントを頼りに正解を当てられれば成功です。

どうしても分からない場合は、`answer/`フォルダの模範解答を確認してください。
