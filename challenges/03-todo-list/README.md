# 03. ToDoリストアプリ

対応セクション: `10.javascript.md` の「配列操作」「オブジェクト操作」「演算子」「DOM API」「セキュリティ意識」


課題
--------------------------------------------------------------------------------

`logic.js` の5つの関数を実装してください（`main.js`・`index.html`は実装済みです）。
すべて**元の配列・オブジェクトを変更せず、新しい配列・オブジェクトを返す**（不変更新）ことを意識してください。

1. `createTodo(id, text)`
   `{ id, text, done: false }` の形のオブジェクトを返してください。

2. `addTodo(todos, todo)`
   `todos`に`todo`を追加した**新しい配列**を返してください（スプレッド構文を使用）。

3. `toggleTodo(todos, id)`
   指定した`id`のtodoの`done`を反転させた**新しい配列**を返してください。
   （`Array.map()`と、スプレッド構文による不変更新を組み合わせます）

4. `removeTodo(todos, id)`
   指定した`id`のtodoを取り除いた**新しい配列**を返してください。

5. `filterTodos(todos, filterType)`
   `filterType`に応じて`todos`を絞り込んでください。
   - `"all"`: すべて
   - `"active"`: `done`が`false`のもののみ
   - `"done"`: `done`が`true`のもののみ


確認方法
--------------------------------------------------------------------------------

1. ロジック部分をターミナルで確認します。

   ```bash
   node challenges/03-todo-list/check.js
   ```

2. 実際にアプリとして動作するか、ブラウザで確認します。
   リポジトリのルートで以下を実行します。

   ```bash
   npx serve .
   ```

   ブラウザで`http://localhost:3000/challenges/03-todo-list/`を開き、
   ToDoの追加・完了切り替え・削除・絞り込みができれば成功です。

どうしても分からない場合は、`answer/`フォルダの模範解答を確認してください。
