# 04. 神経衰弱（Memory Match）

対応セクション: `10.javascript.md` の「配列操作」「オブジェクト操作」「非同期処理（setTimeout）」「演算子」「DOM API」

同じ絵柄のカードを2枚めくって揃える、神経衰弱ゲームです。


課題
--------------------------------------------------------------------------------

`logic.js` の4つの関数を実装してください（`main.js`・`index.html`は実装済みです）。

1. `shuffle(array)`
   配列の要素をランダムに並び替えた**新しい配列**を返してください（元の配列は変更しないこと）。
   Fisher-Yatesアルゴリズムを使用してください。

2. `createDeck(symbols)`
   `symbols`（絵柄の配列）から、各絵柄を2枚ずつ含むカードの配列を作成してください。
   各カードは`{ id, symbol, isMatched: false }`の形にし、`shuffle`を使ってシャッフルしてから返してください。
   （`id`はカードごとに一意な値にしてください）

3. `isMatch(cardA, cardB)`
   2枚のカードが「異なるカードで、かつ`symbol`が一致する」場合に`true`を返してください。

4. `isGameComplete(cards)`
   すべてのカードの`isMatched`が`true`かどうかを、`Array.every()`を使って判定してください。


確認方法
--------------------------------------------------------------------------------

1. ロジック部分をターミナルで確認します。

   ```bash
   node challenges/04-memory-match/check.js
   ```

2. 実際にゲームとして動作するか、ブラウザで確認します。
   リポジトリのルートで以下を実行します。

   ```bash
   npx serve .
   ```

   ブラウザで`http://localhost:3000/challenges/04-memory-match/`を開き、
   カードを2枚ずつめくって、すべて揃えられれば成功です。

どうしても分からない場合は、`answer/`フォルダの模範解答を確認してください。
