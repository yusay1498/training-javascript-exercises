追加チャレンジ（アプリ・ゲーム）
================================================================================

ここにあるのは、`exercises/`の演習とは別の、**任意（ボーナス）の腕試し課題**です。

`exercises/`で学んだ関数・書き方を組み合わせて、簡単なアプリやゲームを一つ完成させる体験を通じて、
「小さな関数の集まりが、動くアプリになる」という感覚を掴むことを目的としています。

各課題は、`exercises/`と同じ構成になっています。

- `logic.js`: 実装対象の純粋な関数（ロジック）。`check.js`で自動採点できます。
- `check.js`: ロジックの自動採点スクリプト。
- `index.html` / `main.js`: 画面表示・DOM操作を行う部分（基本的に実装済みです）。
- `answer/`: 模範解答。


課題一覧
--------------------------------------------------------------------------------

| No | フォルダ | テーマ | 主な復習ポイント |
|----|---------|--------|-----------------|
| 01 | `challenges/01-hit-and-blow` | Hit and Blow | 配列操作、等価演算子、演算子、関数、DOM API |
| 02 | `challenges/02-rock-paper-scissors` | じゃんけんゲーム | 関数、配列操作、オブジェクト操作（不変更新）、スプレッド構文 |
| 03 | `challenges/03-todo-list` | ToDoリストアプリ | 配列操作（map/filter）、オブジェクト操作（不変更新）、DOM API |
| 04 | `challenges/04-memory-match` | 神経衰弱（Memory Match） | 配列操作、オブジェクト操作、非同期処理（setTimeout）、DOM API |


進め方
--------------------------------------------------------------------------------

1. 各フォルダの`README.md`を読み、課題内容を確認してください。
2. `logic.js`内の`// TODO`部分を実装してください。
3. ターミナルで`node challenges/番号-名前/check.js`を実行し、ロジックが正しいか確認してください。
4. リポジトリのルートで`npx serve .`を実行し、ブラウザで実際にアプリ・ゲームとして遊べるか確認してください。
5. 分からない場合は、`answer/`フォルダの模範解答を確認してください。

余裕があれば、`logic.js`にない関数を自分で追加したり、見た目（CSS）を自由にアレンジしてみるのもおすすめです。
