05. thisの挙動
================================================================================

対応セクション: `10.javascript.md` の「thisの挙動」


課題
--------------------------------------------------------------------------------

`todo.js`の3つの関数を実装してください。

1. `createUser(name)`
   `{ name, greet() { ... } }`という形のオブジェクトを返してください。
   `greet`メソッドは`this.name`を使って`"Hello, I'm ${name}"`という文字列を返す、
   **通常の関数（アロー関数ではない）**として実装してください。

2. `detachedGreetUsing(user)`
   `user.greet`メソッドを、`call`を使って`user`を`this`として明示的に指定しながら呼び出し、
   その結果（文字列）を返してください。

3. `createBoundGreeter(user)`
   `user.greet`を`bind`で`user`に固定した、**単体で呼び出せる関数**を返してください。
   （この関数は、後から`user`を渡さずに呼び出しても正しく動作する必要があります）


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/05-this/check.js
```

ヒント
--------------------------------------------------------------------------------

もし`greet`をアロー関数で実装すると、`this`がオブジェクトを指さなくなり、
`this.name`が`undefined`になってしまいます。講義資料の「アロー関数のthis」を読み返してみましょう。
