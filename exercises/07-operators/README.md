07. スプレッド構文・分割代入
================================================================================

対応セクション: `10.javascript.md` の「演算子」（スプレッド演算子・分割代入）


課題
--------------------------------------------------------------------------------

`todo.js`の3つの関数を実装してください。

1. `mergeUnique(arr1, arr2)`
   `arr1`と`arr2`をスプレッド構文で結合し、重複を取り除いた新しい配列を返してください。
   （`Set`を使うと重複を簡単に取り除けます）
   元の`arr1`・`arr2`は変更してはいけません。

2. `updateUser(user, changes)`
   `user`オブジェクトを直接変更せず、`changes`の内容で上書きした**新しいオブジェクト**を返してください。
   （不変更新のパターンです）

3. `getFirstAndRest(arr)`
   配列の分割代入を使って、`{ first: 先頭の要素, rest: 残りの要素の配列 }`を返してください。


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/07-operators/check.js
```
