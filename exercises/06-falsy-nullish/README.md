06. 偽値（Falsy）とNullish
================================================================================

対応セクション: `10.javascript.md` の「偽値（Falsy）とNullish」


課題
--------------------------------------------------------------------------------

`todo.js`の3つの関数を実装してください。

1. `firstTruthy(...values)`
   引数の中から、最初に見つかったTruthy（真とみなされる）な値を返してください。
   全てFalsyだった場合は`undefined`を返してください。

2. `withDefault(value, defaultValue)`
   `value`がNullish（`null`または`undefined`）の場合のみ`defaultValue`を返し、
   それ以外の場合は`value`をそのまま返してください。
   （`0`や`""`はNullishではないので、そのまま返る必要があります）

3. `isEmptyish(value)`
   `value`がFalsyかどうかを判定して返してください。


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/06-falsy-nullish/check.js
```

ヒント
--------------------------------------------------------------------------------

`withDefault(0, 100)`は`0`を返すべきですが、`??`ではなく`||`を使うと`100`が返ってしまいます。
講義資料の「`??`と`||`の違い」を読み返し、なぜそうなるか説明できるようにしましょう。
