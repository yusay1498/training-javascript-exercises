# 04. スコープとクロージャ

対応セクション: `10.javascript.md` の「スコープとクロージャ」


課題
--------------------------------------------------------------------------------

`todo.js`の2つの関数を、クロージャを使って実装してください。

1. `createCounter()`
   呼び出すたびに、以下のメソッドを持つオブジェクトを返してください。
   - `increment()`: カウントを1増やし、増やした後の値を返す
   - `reset()`: カウントを0に戻す
   - `getValue()`: 現在のカウントを返す

   `createCounter()`を複数回呼び出した場合、それぞれのカウンターは独立している必要があります。

2. `createBankAccount(initialBalance)`
   以下のメソッドを持つオブジェクトを返してください。残高（balance）は外部から直接アクセスできないように、
   クロージャで隠蔽してください。
   - `deposit(amount)`: 残高に`amount`を加える
   - `withdraw(amount)`: 残高が`amount`以上であれば引き出して`true`を返す。不足していれば何もせず`false`を返す
   - `getBalance()`: 現在の残高を返す
