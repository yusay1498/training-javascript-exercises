# 11. DOM API

対応セクション: `10.javascript.md` の「DOM API」

**この演習で実装する関数は、`capstone/`で実際にそのまま使います。**

この演習はDOM操作を含むため、Node.jsではなく**ブラウザで動作を確認します**。


課題
--------------------------------------------------------------------------------

`todo.js`の`renderMemberList(container, members)`関数を実装してください。

- `container`の中身を一度空にしてください
- `members`の各要素について`<li>`要素を作成し、`${name} (${score}点)`というテキストを設定してください
- 作成した`<li>`を`container`に追加してください


確認方法
--------------------------------------------------------------------------------

1. リポジトリのルートで以下を実行し、ローカルサーバーを起動します。

   ```bash
   npx serve .
   ```

2. ブラウザで`http://localhost:3000/exercises/11-dom-api/`を開きます。
3. 「Alice (74点)」のように、メンバーの一覧が表示されていれば成功です。
4. DevTools（F12）のConsoleにエラーが出ていないことも確認しましょう。
