03. 関数の定義
================================================================================

対応セクション: `10.javascript.md` の「関数の定義」


課題
--------------------------------------------------------------------------------

`todo.js`に、指定された3種類の書き方で関数を実装してください。

1. `add(a, b)` を**関数宣言**で実装し、`a + b`を返してください。
2. `multiply` を**関数式**で実装し、`a * b`を返してください。
3. `square` を**アロー関数**で実装し、`x * x`を返してください。
4. `makeGreeter(greeting)` を実装してください。
   `greeting`を受け取り、「名前を受け取って`${greeting}, ${name}!`を返すアロー関数」を返す関数です。
   （クロージャの練習を兼ねています）


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/03-functions/check.js
```
