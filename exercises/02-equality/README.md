02. 等価演算子
================================================================================

対応セクション: `10.javascript.md` の「等価演算子」


課題
--------------------------------------------------------------------------------

`todo.js` の2つの関数を実装してください。

1. `isStrictlyEqual(a, b)`
   `===`（厳密な等価演算子）を使って`a`と`b`を比較し、結果を返してください。

2. `describeEquality(a, b)`
   `a`と`b`を`==`で比較した結果と、`===`で比較した結果の両方を、
   `{ loose: boolean, strict: boolean }`というオブジェクトで返してください。


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/02-equality/check.js
```

ヒント
--------------------------------------------------------------------------------

`describeEquality(0, false)`を実行すると、`loose`と`strict`で結果が異なります。
なぜそうなるのか、講義資料の「== vs ===」の節を読み返して説明できるようにしておきましょう。
