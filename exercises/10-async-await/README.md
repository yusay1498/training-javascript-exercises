10. 非同期処理
================================================================================

対応セクション: `10.javascript.md` の「非同期処理」

**この演習で実装する関数は、`capstone/`で実際にそのまま使います。**


課題
--------------------------------------------------------------------------------

`todo.js`の2つの関数を、`async/await`と`try/catch`を使って実装してください。

1. `fetchJson(url)`
   `fetch(url)`を実行し、
   - レスポンスが`ok`でない場合は`Error`を`throw`してください（メッセージに`response.status`を含める）
   - `ok`な場合は、レスポンスを`.json()`でパースして返してください

2. `fetchAllJson(urls)`
   `urls`（URLの配列）を受け取り、`fetchJson`を使って**並列に**すべて取得し、
   結果の配列を返してください（`Promise.all`を使用）。


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/10-async-await/check.js
```

この演習の`check.js`は、実際のネットワーク通信を行わず、
`fetch`を偽のレスポンスに差し替えて動作を確認しています。
