13. セキュリティ意識（XSS対策）
================================================================================

対応セクション: `10.javascript.md` の「セキュリティ意識」

**この演習で実装する関数は、`capstone/`で実際にそのまま使います。**

この演習はDOM操作を含むため、Node.jsではなく**ブラウザで動作を確認します**。


課題
--------------------------------------------------------------------------------

`todo.js`の`renderUserComment(container, comment)`関数を実装してください。

- `comment`はユーザーが自由に入力した文字列という想定です（悪意のある内容が含まれる可能性があります）
- `innerHTML`は**絶対に使用しないでください**
- `textContent`を使って、HTMLとして解釈されない安全な方法で表示してください


確認方法
--------------------------------------------------------------------------------

1. リポジトリのルートで以下を実行し、ローカルサーバーを起動します。

   ```bash
   npx serve .
   ```

2. ブラウザで`http://localhost:3000/exercises/13-security-xss/`を開きます。
3. **アラート（ポップアップ）が表示されなければ成功です。**
   画面には`<img ...>`というタグの文字列がそのままテキストとして表示されていればOKです。
4. もしアラートが表示されてしまった場合、`innerHTML`を使ってしまっている可能性があります。
   実装を見直してください。
