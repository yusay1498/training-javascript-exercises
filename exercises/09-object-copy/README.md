# 09. オブジェクト操作

対応セクション: `10.javascript.md` の「オブジェクト操作」

**この演習で実装する関数は、`capstone/`で実際にそのまま使います。**


課題
--------------------------------------------------------------------------------

`todo.js`の3つの関数を実装してください。

1. `shallowCopyUser(user)`
   スプレッド構文を使って`user`の**浅いコピー**を返してください。

2. `deepCopyUser(user)`
   `structuredClone`を使って`user`の**深いコピー**を返してください。

3. `updateAge(user, newAge)`
   `user`を直接変更せず、`age`だけを`newAge`に置き換えた新しいオブジェクトを返してください（不変更新）。


確認方法
--------------------------------------------------------------------------------

```bash
node exercises/09-object-copy/check.js
```

ヒント
--------------------------------------------------------------------------------

浅いコピーと深いコピーの違いは、ネストしたオブジェクト（`address`など）に対する変更が
元のオブジェクトに影響するかどうかで確認できます。講義資料の「浅いコピー」「深いコピー」の節を参照してください。
