01. 変数と型の基礎
================================================================================

対応セクション: `10.javascript.md` の「変数と型の基礎」


課題
--------------------------------------------------------------------------------

`todo.js` の3つの関数を実装してください。

1. `safeTypeOf(value)`
   `typeof`演算子には「`typeof null`が`"object"`になる」という歴史的なバグがあります。
   この関数では、`value`が`null`の場合は`"null"`を、それ以外は`typeof value`の結果を返してください。

2. `toNumberOrZero(value)`
   `Number()`を使って`value`を明示的に数値へ変換してください。
   変換結果が`NaN`になった場合は、代わりに`0`を返してください。

3. `isActuallyNaN(value)`
   `value`が本当に`NaN`かどうかを、`Number.isNaN()`を使って正しく判定してください。
   （`isNaN()`ではなく`Number.isNaN()`を使う理由を思い出しましょう）

--------------------------------------------------------------------------------

node exercises/01-variables-types/check.js
